# تقرير الاختبارات الحقيقية — Whisper والترجمة والتصدير

**التاريخ:** 21 أكتوبر 2026

## البيئة

- المتصفح: Chromium 154.0.8037.57 على ARM64 / Ubuntu 24.04.
- Firefox غير مثبت في بيئة الاختبار.
- خادم التطوير المحلي على المشروع.
- لم تتم إضافة ملفات الصوت أو الفيديو التجريبية إلى المستودع.

## اختبار Whisper

تم إنشاء فيديو MP4 مدته 20.08 ثانية يحتوي على كلام إنجليزي واضح، وليس ملفًا صامتًا أو نغمة صوتية. شُغّل الفيديو داخل `/studio`، وتم اختيار English، ثم تشغيل زر تحليل الكلام.

النتيجة:

- تم تنزيل وتشغيل نموذج `Xenova/whisper-tiny` داخل Worker محلي.
- استخرج النظام 48 كلمة بتوقيتات فعلية.
- ظهرت عبارات النص واقتراحات المقاطع داخل الواجهة.
- نجح المسار المحلي دون رفع الفيديو إلى الخادم.

**الحالة: ناجح.**

## اختبار الترجمة

بعد نجاح التفريغ، تم الانتقال إلى التحرير واختيار French، ثم تشغيل الترجمة المحلية.

النتيجة:

- تم تنزيل وتشغيل نموذج OPUS-MT المحلي.
- ظهرت الترجمة الفرنسية داخل محرر captions.
- تم حفظ التوقيتات على مستوى العبارات.
- ظهر تحذير tokenizer معروف: `MarianTokenizer is not yet supported by the fast tokenizers library`. التحذير غير مانع، لكنه يبرر مراجعة النص المترجم قبل النشر.

**الحالة: ناجح مع ضرورة المراجعة البشرية للترجمة.**

## اختبار التصدير

Chromium في هذه البيئة لم يوفّر زوج H.264/AAC المطلوب لإخراج MP4، وأظهر التطبيق الصيغة المتاحة بوضوح:

`WebM / VP9 + Opus detected on this device`

تم تصدير المقطع بالصيغة المتاحة WebM فعليًا:

- التصدير اكتمل.
- ظهر الناتج داخل واجهة النتائج.
- الحجم: 854KB تقريبًا.
- لم تظهر أخطاء JavaScript قاتلة.

**MP4: غير مثبت في بيئة Chromium الحالية بسبب غياب H.264/AAC WebCodecs، وليس بسبب فشل في مسار التصدير.**

**WebM: ناجح.**

## Firefox

لم يتم تشغيل اختبار Firefox لأن Firefox غير مثبت في بيئة التنفيذ الحالية. لا يدّعي هذا التقرير دعم Firefox أو فشل دعمه.

## الحكم

المسارات الفعلية التي تم إثباتها:

1. كلام حقيقي → Whisper محلي → 48 كلمة مؤقتة — ناجح.
2. النص الناتج → ترجمة فرنسية محلية — ناجح.
3. الفيديو → قص وتصدير WebM على Chromium — ناجح.
4. MP4 يعتمد على توفر H.264/AAC في المتصفح؛ Chromium الحالي اختار WebM تلقائيًا.

الصياغة الصحيحة للبيع:

> Export format depends on browser codec support. WebM is supported in the tested Chromium environment; MP4 is available only on browsers that provide H.264/AAC WebCodecs.
