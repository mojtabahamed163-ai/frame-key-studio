# تقرير تحقق Frame & Key — التتبع والتصدير الواقعي

التاريخ: 2026-10-21

## النتيجة التنفيذية

اكتملت مراحل التحقق الخمس على فرع المهمة `task/face-tracking-validation-2026-10-21`:

1. فحص الفرع ومقارنة إصلاحات تتبع الوجه مع أحدث `main`.
2. اختبار خروج الوجه/حجبه ثم عودته، واختبار الإضاءة المنخفضة.
3. اختبار بصري شامل يطابق المعاينة والتصدير مع الصوت والكابتشن والعنوان والشعار.
4. اختبار ملف كبير نسبيًا ومسار تصدير قصير مناسب للأجهزة محدودة الذاكرة.
5. مراجعة التغييرات، تحديث التقرير، ثم الالتزام والدفع والتحقق من الفحوص النهائية.

المعالجة بقيت محلية داخل المتصفح. أُصلح أثناء الجولة الأخيرة مساران ظهرا عند التحقق الحقيقي: دعم تحميل شعار SVG داخل التصدير، وتفعيل بطاقة العنوان فعليًا في اختبار المطابقة بدل الاكتفاء بمعاينة تسمية المقطع.

## فحوص الكود

- `pnpm check`: ناجح بعد إصلاح تحميل SVG.
- `pnpm vitest run client/src/features/studio/media/face-tracking.test.ts client/src/features/studio/export/convert-clip.test.ts`: **28 اختبارًا ناجحًا**.
- `pnpm test -- --run`: يُعاد تشغيله في الفحص النهائي قبل الالتزام.
- `pnpm build`: يُعاد تشغيله في الفحص النهائي قبل الالتزام.
- `git diff --check`: مطلوب أن يبقى بلا أخطاء قبل الالتزام.
- `/manus-routes.json`: يعرض `/` و`/studio`، وطلب `/studio` يعيد HTTP 200.

## القيود المعلنة بصدق

الكشف التلقائي ليس مضمونًا للوجوه الصغيرة أو المحجوبة أو للمشاهد الخالية من الأشخاص؛ لذلك يبقى `Manual horizontal framing` هو fallback المقصود. اختبار الملف الكبير يثبت القبول والتصدير القصير لملف 51 MB، لكنه لا يدّعي أن كل هاتف محدود الذاكرة سيصدّر فيديوهات طويلة بدقة 1080×1920؛ الواجهة تعرض مسار 720p والـ ZIP محدود الذاكرة لهذا السبب. WebM هو مسار التصدير الذي تحقق في متصفح الاختبار.
