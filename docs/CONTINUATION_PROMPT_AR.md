# رسالة جاهزة للحساب الجديد

أنت تتابع مشروع **Frame & Key Studio** من المستودع:

`https://github.com/mojtabahamed163-ai/frame-key-studio`

ابدأ بقراءة:

1. `docs/face-tracking-vertical-cropping-report-ar.md` — التقرير الأحدث لهذه المهمة، وفيه حالة الفرع والاختبارات والسيناريوهات الناقصة.
2. `HANDOFF.md`
3. `README.md`
4. `TODO.md`
5. `docs/validation-report-2026-10-15.md` — سجل تاريخي أقدم، لا يتقدم على نتائج التقرير الأحدث.

المطلوب هو متابعة تحسين محرر الفيديو الحالي، وليس إعادة بناء التطبيق. التطبيق يعمل محليًا داخل المتصفح باستخدام React/Vite/Mediabunny/Whisper Tiny/MediaPipe. لا تستخدم API مدفوعة، ولا ترفع ملفات الفيديو إلى الخادم.

الميزات المهمة الموجودة:

- قص Fill إلى 9:16.
- Show Full Video داخل خلفية استوديو.
- كابتشن مستورد أو مولّد محليًا وحرقه داخل الفيديو.
- عنوان وهوية بصرية.
- تصدير WebM محليًا بدقة 720×1280 أو 1080×1920.
- اكتشاف الوجه محليًا مع fallback يدوي.
- حفظ المشاريع والإعدادات محليًا في المتصفح.

آخر إصلاح مهم سابق: إذا ظهر `showSaveFilePicker` في المتصفح دون أن تظهر نافذة الحفظ، لا يجب أن يبقى التصدير عند 0%. توجد مهلة 2.5 ثانية في `requestSaveTarget` ثم يعود التطبيق إلى BufferTarget.

نتائج اختبار القص/التتبع الأحدث موجودة بالتفصيل في التقرير. نُفّذت `pnpm check` و`pnpm test` (55 اختبارًا) و`pnpm build` و`git diff --check` بنجاح. الإصلاح مرفوع على فرع `task/face-tracking-vertical-cropping`؛ راجع commit SHA والسيناريوهات التي لم تُختبر بعد في التقرير قبل متابعة العمل. لا تخلط هذه النتائج مع الأرقام التاريخية التالية.

النتائج التاريخية قبل مهمة القص الحالية:

- 32 اختبارًا ناجحًا.
- بناء الإنتاج ناجح.
- تم اختبار خمسة فيديوهات: close-up، حركة، محاضرة بعيدة، عدة عناصر، وتسجيل شاشة.
- MediaPipe قد يفشل مع الوجوه الصغيرة أو الفيديو الاصطناعي؛ لا تحذف الضبط اليدوي. حسّن التتبع عبر Canvas، آخر وجه موثوق، IoU، عتبات الثقة، التغطية الزمنية، وsmoothing متكيف.

نفّذ قبل التعديل:

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
```

ونفّذ بعد التعديل:

```bash
pnpm check
pnpm test
pnpm build
git diff --check
```
