# المرحلة 07 — الاستقلالية والأمان

**التاريخ:** 2026-11-15

## الحالة

اكتملت المرحلة السابعة. تم فحص الملفات المتعقبة، مراجع الحسابات الخارجية، تاريخ Git القابل للوصول، وتبعيات الإنتاج. النتيجة تؤكد أن مسار `/studio` المحلي لا يحتاج حساب Manus أو Forge أو API inference مدفوع لتشغيل Whisper، اقتراحات المقاطع، captions، الترجمة، والتصدير.

## نتائج فحص الأسرار

- الملف البيئي المتعقب الوحيد هو `.env.example`، وقيمه placeholders مثل `USER:PASSWORD@HOST` و`your-oauth-service.example`.
- لا توجد ملفات مفاتيح خاصة أو credentials متعقبة.
- فحص تاريخ Git عن signatures عالية الثقة لمفاتيح AWS وOpenAI وGitHub ومفاتيح RSA/OPENSSH لم يعثر على نتيجة.
- أسماء `MANUS_*` و`DATABASE_URL` الموجودة في الشيفرة هي أسماء إعدادات لمسارات موروثة أو اختيارية، وليست قيمًا سرية.
- ملفات `dist/` و`node_modules/` الناتجة عن الاختبارات بقيت ignored ولم تدخل Git.

## استقلال مسار Studio

مصادر الاستقلال موثقة في الشيفرة ومثبتة عمليًا في المراحل السابقة:

- ملف الفيديو يبقى داخل المتصفح ويُقرأ بواسطة Mediabunny.
- Whisper يعمل داخل Web Worker باستخدام Transformers.js وONNX/WASM.
- نماذج Whisper المستخدمة هي `Xenova/whisper-base.en` للإنجليزية و`Xenova/whisper-tiny` للمسارات متعددة اللغات.
- الترجمة الإنجليزية → العربية تستخدم `onnx-community/opus-mt-en-ar` داخل Worker مستقل.
- التصدير يتم محليًا باستخدام Mediabunny إلى WebM.
- النماذج العامة تُنزّل من Hugging Face عند أول استخدام وتُخزّن في cache المتصفح؛ هذه هي الحاجة الشبكية التشغيلية الوحيدة للمسار المحلي الأولي، وليست اعتمادًا على حساب Manus/Forge.

أما OAuth وDrizzle/MySQL وnotification ومسارات `/api/leads` فهي مكونات موروثة اختيارية خارج مسار تحرير الفيديو المحلي، وتحتاج إعدادات المشتري فقط عند استخدام تلك الخدمات.

## فحص التبعيات

تم تنفيذ:

```text
pnpm audit --prod
```

والنتيجة:

```text
No known vulnerabilities found
```

كما أن `pnpm check` و`pnpm test` و`pnpm build` نجحت في المرحلة السادسة، ما يثبت أن التحقق الأمني لم يكن منفصلًا عن قابلية البناء.

## التحفظ التشغيلي الصريح

الاستقلال لا يعني أن أول تشغيل يعمل بلا إنترنت؛ ملفات النماذج العامة تحتاج تنزيلًا أوليًا من Hugging Face. بعد تنزيلها، تثبت الأدلة السابقة أن التحليل والترجمة والتصدير تتم محليًا. كما أن وظائف الموقع الموروثة خارج `/studio` قد تحتاج credentials يملكها المشتري، لكنها ليست شرطًا لمسار المنتج الذي تم التحقق منه.

## خلاصة المرحلة

لا توجد أسرار عالية الثقة في الشجرة أو تاريخ Git المفحوص، ولا توجد ثغرات معروفة في تبعيات الإنتاج حسب `pnpm audit --prod`. مسار Studio مستقل تشغيليًا عن حسابات Manus/Forge، مع توثيق واضح لحاجة تنزيل نماذج عامة في أول استخدام.
