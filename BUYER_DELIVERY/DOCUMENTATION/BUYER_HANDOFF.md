# Buyer Handoff

## Repository and branch

The source repository is `https://github.com/mojtabahamed163-ai/frame-key-studio`. This delivery is prepared on branch `buyer-delivery-2026-11-16`. The final commit is the pushed branch tip; its SHA is included in the completion message.

## Local operation

Use `pnpm install --frozen-lockfile`, then `pnpm dev:static` and open `/studio`. The Studio is browser-local and keeps project state in the active browser profile. It is not automatically synchronized between browsers or devices.

## Build and optional server shell

Use `pnpm check`, `pnpm test -- --run`, and `pnpm build`. The built server shell can be started with `NODE_ENV=production PORT=3000 pnpm start`, but server-side features need their documented environment and database configuration. Do not interpret a missing server integration as a failure of the local media workflow.

## Important configuration

Do not commit `.env` files, credentials, model weights, private media, database dumps, or API keys. The local Studio needs browser storage, WebAssembly, media decoding, and first-use public model downloads. Export behavior depends on WebCodecs and encoder support in the browser/device.

## Known limitations

Whisper output requires human correction. Machine translation may contain linguistic errors and is phrase-timed. Face tracking is optional and must not be described as universally verified. WebM is the verified export format in the available evidence. Browser compatibility, long-export memory behavior, model download availability, and platform upload acceptance require buyer-specific testing. The historical 70-second recording remains unavailable; the new long buyer demonstration is separate. No production URL, hosted SaaS, revenue, customer traction, or billing system is claimed.
