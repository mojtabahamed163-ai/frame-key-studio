# Frame & Key Studio — Buyer Delivery Package

This is an independently checked buyer package that preserves existing evidence, documents the recovered Spanish export, and distinguishes new recordings from missing historical artifacts.

- `DEMO/` — preserved genuine recordings, the enhanced 5-minute buyer demo, its byte-identical MP4 backup under `Backup/`, the unchanged root-level source demo, and the preferred visual retake under `Visual-Retake/`.
- `EXPORTS/` — verified historical source-language and bilingual Arabic WebM exports plus Spanish WebM exports created through the real local Studio workflow.
- `SOURCE/` — genuine source WebM used for the demonstrations.
- `REPORTS/` — final status, feature matrix, limitations, FFprobe output, hashes, and demo verification.
- `DOCUMENTATION/` — buyer overview, architecture, installation, and handoff.
- `VERIFICATION/` — full-decode logs, FFprobe JSON, and representative frames.

**Buyer-facing demo:** `DEMO/Frame-and-Key-Studio-Complete-Buyer-Demo-Cursor-Enhanced.mp4` is the 300.920-second (5:00.920) H.264 1920×1080/25 fps demo with an emphasized source-captured cursor and brief callouts aligned to visible UI transitions. Cursor movement/click telemetry is not present in the source, so no mouse paths or unsupported click coordinates are fabricated. The unchanged source MP4 is backed up at `DEMO/Backup/Original-Complete-Buyer-Demo-UNCHANGED.mp4`.

**The new continuous buyer demonstrations remain available.** The preferred visual retake is 313.040 seconds (5:13.040), H.264, 1920×1080 at 25 fps, video-only/silent, and shows the English-to-Spanish workflow with `Sin embargo,` visibly over the portrait preview. The original historical 70-second recording remains unavailable and is accurately marked in `DEMO/70-Second-Recording.NOT_FOUND.txt`; it is distinct from the new demonstration. The Spanish export is a selected 28.989-second clip, not a full-length source export.
