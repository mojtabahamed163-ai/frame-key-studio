# Known Limitations and Open Gaps

1. The requested original historical 70-second screen recording was not found. Its `DEMO/70-Second-Recording.NOT_FOUND.txt` marker remains. The new 5–8 minute recording is a separate deliverable, not a recovered copy.
2. The preserved historical recordings are 135.520 and 142.960 seconds; they are not substitutes for the new end-to-end recording or the original 70-second artifact.
3. The recovered/historical and newly rendered Spanish exports are selected 28.989-second clips, not full 6:54 source-length exports; translation is machine-generated and may contain linguistic errors.
4. A previous edited historical buyer-demo MP4 documents an export failure. The new 5:00.920 root-level recording and the 5:13.040 visual retake are separate successful application demonstrations. Both screen recordings are silent/video-only because this capture environment had no usable system-audio device.
5. Whisper output is a draft and may require human correction for names, punctuation, timing, accents, and difficult audio.
6. Machine translation uses phrase-level timing rather than word-level translation alignment and requires human review.
7. Face assistance tracks visible faces and does not identify a speaker; support is not universal.
8. WebM/VP9 + Opus is the verified export path in the supplied evidence. MP4 export is conditional and browser-specific.
9. Browser/device compatibility, long-export memory limits, first-use model downloads, and social-platform upload acceptance require additional buyer testing.
10. The core application is browser-local, not a hosted production SaaS. There is no production URL, managed account system, subscription system, proven revenue, or commercial customer claim.
11. The repository includes an inherited server shell whose database/OAuth/platform features require separate configuration.
